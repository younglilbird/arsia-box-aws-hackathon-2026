# Fictional report examples

These are real two-page Word/PDF exports from the fictional Alex Chen demo,
with a separate evaluation document. No real employee records are included.

- [Annual review, Word](annual-review.docx)
- [Annual review, PDF](annual-review.pdf)
- [Current evaluation, Word](evaluation.docx)

The report contains four main sections and paragraph-based project narratives.
Formal exports omit evidence markers; the workbench retains source quotations
for review. The evaluation describes the report, not the employee's performance.
All examples remain drafts awaiting employee review.

Inputs are in [demo-materials](../demo-materials/README.md). Generation, recovery
and content-refinement provenance is recorded in the
[development checks](../docs/development-checks.md). These static examples are
not a hosted application or a new live generation.
